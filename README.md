# ProyectoFinal_SQL-Caso_Estudio_DataAndino-DRE
Proyecto realizado con SQL en Databricks para analizar las cancelaciones de reservas del hotel DataAndino. Se busca identificar pérdidas económicas y factores que influyen en las cancelaciones mediante consultas SQL, limpieza de datos, agregaciones y JOINs.

##Fuente de datos (Kaggle): https://www.kaggle.com/datasets/datacertlaboratoria/sql-proyecto-1-analisis-de-cancelaciones-hoteleras
